# 💰 Finance Dashboard

## 📌 Overview
This project is a Finance Dashboard UI built using React.
It allows users to track financial activities, view insights, and manage transactions.

## 🚀 Features
- Dashboard with Balance, Income, Expenses
- Line & Pie charts (Recharts)
- Transactions (Add, Delete, Search, Sort)
- Role-based UI (Viewer/Admin)
- Insights (Savings, Monthly comparison)
- Dark Mode 🌙
- Responsive design
- LocalStorage persistence

## 🛠️ Tech Stack
- React (Vite)
- Tailwind CSS
- Recharts
- Zustand

## ⚙️ Setup
git clone https://github.com/YOUR-USERNAME/finance-dashboard.git
cd finance-dashboard
npm install
npm run dev
